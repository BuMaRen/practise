# 系统设计学习

本分支仅用于系统设计学习，不包含页面、程序或其他学习内容。每天完成一道贴近生产的系统设计题，从中低难度起步，逐渐增加复杂度。

在仓库根目录运行 `./system-design/practise` 可从终端进入学习；脚本支持查看今日/最新题目、列出题目、按日期查看和显示材料目录。使用 `./system-design/practise help` 查看命令。

## 长期学习材料

- [设计方法与常见设计](design-methods.md)：如何评估需求、估算规模、组织方案、分析取舍和验证设计。
- [常用系统设计概念](concepts.md)：恢复原仓库的 28 个概念，按主题和优先级整理。
- [答题模板](answer-template.md)：设计时要考虑的角度及其原因，不给出特定题目的方案提示。
- [AI 评审标准](evaluation-rubric.md)：统一评估设计是否合格及其质量。
